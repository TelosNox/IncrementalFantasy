Verdeckung und Text: D = 32 gegen D = 40

Platzhalter-HUD (Name + HP) im 24-su-Kopfraum über jeder Figur. Frage: Leidet die Lesbarkeit unter der stärkeren Verdeckung bei 32? Mit dem dritten Schalter lässt sich die Kontrastplatte hinter dem Text abschalten — dann sieht man, was Text ohne Platte auf einem Sprite anrichtet.

D = (+32, −32) — B₂ = 236 / B₁ = 268

Horizontale Überlappung der Sprite-Boxen: 32 su. Mittelgang 48 su.

D = (+40, −40) — B₂ = 228 / B₁ = 268

Horizontale Überlappung: 24 su. Mittelgang 32 su.
